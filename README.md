# 打盗工作台（Chrome 扩展）

给作者自己用的打盗工具。它会在你的 Chrome 里搜索盗文，交给你逐条确认，帮你核验、截图取证，再整理成投诉材料。在投诉页面上，它可以帮你填表。

设计依据是碧水江汀里的打盗经验，主要来自「防盗助手四档思路」帖和「自制打盗软件」帖里开发者坛友列的风险清单：

- 所有资料只存在你本机的浏览器里，没有服务器，也没有云同步。
- 每条链接都由你人工确认，只有标成「盗文」的链接才会进入投诉材料。
- 不自动提交投诉。协议勾选、证件上传、验证码、提交按钮，都由你自己操作。
- 不绕过验证码。搜索引擎弹出验证时，工具会暂停，等你手动完成。
- 搜索之间会随机等待，并设有单轮和每日上限，避免被搜索引擎软封禁。
- 内置正版渠道白名单，自动排除晋江链接。请把合作渠道站也补进白名单。

---

## 安装（大约 1 分钟）

1. 把压缩包解压到一个固定的文件夹，比如 `文档/打盗工作台`。之后不要删除或移动这个文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions`，然后回车。
3. 打开右上角的「开发者模式」。
4. 点「加载已解压的扩展程序」，选择刚才解压出来的文件夹（里面有 `manifest.json` 的那一层）。
5. 点浏览器右上角的拼图图标，把「打盗工作台」固定到工具栏，之后点它就能打开。

Edge 浏览器也可以用。入口是 `edge://extensions`，步骤相同。

## 使用流程

按左侧的 1～5 步走即可。

### 1. 作者资料
填写真实姓名、手机、邮箱和地址，这些是投诉表单里反复要填的内容。

身份证和合同扫描件不放进工具。工具里只记它们放在哪个文件夹，上传时你自己手动选文件。

### 2. 作品库
**最快的方法：粘贴晋江作品链接，点「读取并添加」。** 支持电脑版链接（`onebook.php?novelid=…`）和手机版链接（`m.jjwxc.net/book2/…`）。工具会自动读取以下信息，你核对后点「保存作品」：

- 书名、笔名、文案、正版链接
- 首发时间（第 1 章的首发时间）
- 分类、连载状态、字数和标签（写进备注）
- 候选指纹句：从免费的第 1 章自动挑 3 句叙述句

有两项需要你自己补：
- **旧书名**：晋江页面上没有显示。
- **付费章节的指纹句**：再补 2～3 句。盗文站最想偷的是付费内容，用付费章节的句子核验最准。

编辑已有作品时，「从晋江补全空着的项」只会填空着的格子，不会覆盖你已经改过的内容。

每本书最终需要的信息：书名、旧书名、笔名、正版链接、首发时间。

最重要的是**指纹句**：从正文里挑 3～5 句有辨识度的原句，最好来自付费章节，每句 15 字以上。工具会用它们做两件事：

- 搜索：取每句的前 24 字去搜；
- 核验：检查盗文页面里有没有出现这些句子。

> 千万不要删文、删号重发，首发时间是你证明权属的关键证据。

### 3. 搜索盗文
1. 勾选要搜的作品和搜索入口（百度、夸克、必应等），点「开始搜索」。
2. 工具会打开一个单独的「搜索窗口」，一条一条地搜。**搜索期间请保持工作台页面开着。**
3. 如果某个搜索引擎要求验证，工具会暂停并切到搜索窗口。你手动完成验证后，回到工作台点「我已完成验证，继续」。
4. 很多盗文站只在手机上显示正文。可以在「设置」里打开「用手机身份搜索、核验和截图」。

### 4. 人工审核
每条候选链接都会显示疑似度、发现它的搜索引擎、摘要和类型（网页、网盘、社交平台）。审核的步骤：

1. **核验**：工具抓取页面，检查有没有书名和指纹句，结果类似「指纹 2/3，含书名」。第一次核验时 Chrome 会询问是否允许访问网站，点允许即可。
2. **打开看**：自己点开确认。按 `O` 也可以打开当前这一行。
3. **标记**：把链接标成盗文、推文、正版、失效、空壳或无关。
   - 快捷键：`J`、`K` 上下移动；`1` 盗文、`2` 推文、`3` 正版、`4` 失效、`5` 空壳、`6` 无关；`V` 核验。
4. **截图取证**：工具会打开页面并截图，在图片底部印上网址、页面标题和取证时间，保存到下载文件夹。

**判断标准：**

| 情况 | 标成 |
|---|---|
| 页面里有正文 | 盗文 |
| 网盘里是文包 | 盗文 |
| 只推荐、不放正文或资源的推文 | 推文（不要投诉） |
| 晋江或合作渠道 | 正版（千万不要投诉） |
| 有书名但只有广告 | 空壳 |
| 打不开、404 | 失效 |

### 5. 投诉材料
已确认的盗文会自动按「四档」分好组：

| 档位 | 分组方式 | 怎么投诉 |
|---|---|---|
| 第一档：盗文网页 | 按「在哪个搜索引擎上发现的」分组 | 向对应搜索平台提交版权投诉，删除搜索结果；也可以走晋江快速通道 |
| 第二档：网盘 | 按网盘服务商分组 | 分别向各网盘投诉 |
| 社交平台 | 按平台分组 | 逐条投诉（再确认一遍不是推文） |
| 第三档：域名 | 列出所有盗文站的域名，附 ICANN 查询链接 | 查到注册商和托管服务商后，向服务商投诉 |

每组都可以复制链接、复制或下载权利通知书。通知书的内容按《信息网络传播权保护条例》要求的要素生成：权利人身份、联系方式、作品名称、侵权网址、承诺声明。投诉成功后点「记录为已投诉」，下次打开就能看到哪些链接已经投诉过。

**投诉页地址需要你自己填。** 各平台的版权投诉入口经常变化，工具里没有预置。请从作者区的打盗教程里找到地址，核对无误后，填进「设置 → 投诉入口」。

### 一键填好必应表单
在「投诉材料 → 第一档 → 在必应上发现」那一组，点「一键填好必应表单」。工具会打开必应的版权投诉表单，自动填好以下内容：

- 姓名、版权人、国家、邮箱
- 作品类型、书名、正版链接
- 英文说明
- 所有还没投诉过必应的盗文链接：超过 10 条时，自动生成批量 txt 上传
- 附件：中英文权利通知书

页面顶部会出现提示条。表单里画了红框的三项声明、电子签名和 Submit 按钮，需要你核对后**自己**勾选、签名、提交。提交成功后，点提示条上的「我已提交成功，记录投诉」。

使用前，请在「作者资料」里填好拼音姓名和邮箱。必应会把投诉信息转给对方或公开，建议用一个打盗专用邮箱。

### 一键填好夸克表单
在「投诉材料」里，夸克网盘那一组（第二档）和「在夸克上发现」的网页那一组（第一档）都有「一键填好夸克表单」按钮。

第一次用之前，请在夸克侵权投诉平台（ipp.quark.cn）登录，并在「实名认证」里添加好权利人。

点按钮后，工具会打开投诉平台，自动完成：
- 选好「权利人 → 知识产权 → 著作权 → 夸克网盘（或夸克搜索）→ 小说」，并选上权利人；
- 逐行填入侵权链接、作品名称和访问码（一次最多 50 条）。访问码从链接里的 `pwd=` 或备注里的「提取码：xxxx」读取；
- 写好投诉描述。

剩下的由你自己完成：在红框处上传证明文件（签字的通知书、首发证明或合同，「可打印的通知书」按钮能生成一份）和侵权截图，核对后点「提交」。提交成功后，点页面底部提示条上的「我已提交成功，记录投诉」。

### 6. 投诉跟踪
所有记录过「已投诉」的链接都会列在这里，显示投诉过哪些平台、哪天投诉的。

- **复查链接**：重新打开每条链接，看它还在不在。结果分四种：
  - **已失效**：404，或网盘提示「分享不存在 / 已失效」；
  - **仍可访问**：页面里还能找到书名或指纹句；
  - **待确认**：页面还在但看不出是不是你的文，需要你打开看一下；
  - **未复查**：还没复查过。
- **重新搜索**：把当初找到这些链接的搜索词再搜一遍。「搜索结果」一栏会显示投诉后它还搜不搜得到。重搜计入每日搜索次数。
- 仍可访问的链接可以点「再投诉」，回到投诉材料再投一次。
- 「导出表格」可以把整张跟踪表存成 CSV。

投诉一般要几天处理，建议投诉一周后再复查。

### 填写助手（在投诉页面上用）
1. 打开某个平台的投诉页面。
2. 点工具栏里的「打盗工作台」图标，选「在当前页面打开填写助手」。
3. 先点表单里要填的输入框，再点助手里的条目（姓名、作品名、侵权链接、通知书全文等），内容就会填进去。
4. 多条链接逐个填写时，可以选「追加到末尾」。

助手只负责填写。勾选协议、上传证件、验证码和提交都要你自己完成。提交成功后，可以在助手底部记录这次投诉。

如果投诉表单嵌在 iframe 里，助手可能填不进去，这时用每个条目旁边的「复制」即可。

## 权限说明

| 权限 | 用途 |
|---|---|
| 存储 | 把资料保存在本机 |
| 标签页、脚本注入 | 打开搜索窗口、读取搜索结果、在投诉页面打开填写助手 |
| 搜索引擎域名访问 | 读取百度、夸克、必应、搜狗、360、头条、微博的搜索结果页 |
| 访问所有网站（可选，第一次核验或截图时才询问） | 核验盗文页面内容、截图取证。随时可以在扩展详情页关闭 |
| 修改请求头 | 仅在开启「手机身份」时，把搜索窗口和核验请求伪装成手机浏览器 |

工具不会向任何第三方服务器发送你的资料。

## 注意事项

- **举报责任在举报人。** 有的平台收到投诉会直接屏蔽链接。如果误报了正常推文或正版渠道，对方可以申请恢复，甚至追究举报人。每条链接都请亲自打开确认。
- **控制搜索频率。** 默认每次间隔 20～45 秒，单轮最多 30 次，每天最多 120 次。调太快会被搜索引擎软封禁，之后连续几天都可能搜不出结果。
- **不要把这个工具改造成「全自动提交」再分享给别人**，坛友提醒过这有法律风险。
- **备份文件里有你的真实信息**，不要发给别人。
- 如果你把工具分享给其他作者，建议原样分享，并让对方自己检查代码。所有代码都在文件夹里，可以直接打开阅读。

## 已知局限

- 我只用模拟的搜索结果页测试过，还没有在真实的百度、必应页面上跑过。各搜索引擎的页面结构会变，某个入口如果突然一条结果都读不出来，多半是页面改版了。夸克、头条/悟空、微博用的是通用解析，准确度比百度、必应、搜狗、360 低。
- 有些盗文站用 JavaScript 加载正文，或者对正文做了混淆。这类页面核验可能显示「无书名」或「页面几乎无文字」，需要你打开页面人工判断，再截图取证。
- 少数结果是搜索引擎的跳转链接，工具解析不出真实网址，会标注「跳转链接」。点「核验」或手动打开后，就能看到真实网址。
- 工具只负责发现、整理和填写，投诉能否成功取决于各平台的审核。

## 文件说明

|---|---|
| `manifest.json` | 扩展配置 |

| `assist.js` | 填写助手 |
