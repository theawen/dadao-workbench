# 晋江打盗工作台

给晋江作者自己用的 Chrome 扩展，用来找盗文、留证据、写投诉。它在你自己的浏览器里搜索疑似盗文，由你逐条确认，然后帮你核验、截图取证，并整理成投诉材料。到了投诉页面，它还能帮你填表。

> 这是作者自发做的个人项目，和晋江文学城官方没有关系。

## 设计原则

参考了碧水江汀里的打盗经验，主要是「防盗助手四档思路」帖，以及「自制打盗软件」帖里开发者坛友列出的风险清单：

- **资料只存在本机。** 所有内容都保存在你自己的浏览器里，没有服务器，也没有云同步。
- **每条链接都要人工确认。** 只有你标成「盗文」的链接，才会进入投诉材料。
- **不替你提交投诉。** 勾选协议、上传证件、输入验证码、点提交，都由你自己来。
- **不绕过验证码。** 搜索引擎要求验证时，工具会暂停，等你手动完成。
- **控制搜索节奏。** 每次搜索之间随机等待，单轮和每天都有次数上限，避免被搜索引擎软封禁。
- **自带正版白名单。** 晋江的链接会被自动排除。如果你的作品还有合作渠道，请把那些网站也加进白名单。

## 安装

这个扩展没有上架 Chrome 应用商店，要用「开发者模式」加载，整个过程大约 1 分钟。

### 第一步：把代码下载到电脑上

下面两种方法任选一种：

- **用 git**：
  ```bash
  git clone https://github.com/theawen/dadao-workbench.git
  ```
- **不用 git**：在本仓库页面点绿色的「Code」按钮，选「Download ZIP」，下载后解压。解压出来的文件夹叫 `dadao-workbench-main`。

把文件夹放在一个固定的位置，比如「文稿」里。**装好以后，不要移动、重命名或删除这个文件夹。** Chrome 是按文件夹的位置来认这个扩展的，位置一变，就读不到工具里原来存的资料了。

### 第二步：在 Chrome 里加载

1. 在地址栏输入 `chrome://extensions`，回车。
2. 打开右上角的「开发者模式」。
3. 点「加载已解压的扩展程序」，选中刚才那个文件夹（`manifest.json` 所在的那一层）。
4. 点浏览器右上角的拼图图标，把「打盗工作台」固定到工具栏。以后点这个图标就能打开工作台。

Edge 浏览器也能用，入口是 `edge://extensions`，步骤相同。

## 更新到新版本

1. 先在工作台的「设置与备份」里点「导出备份」，以防万一。
2. 获取新版本：
   - 用 git 下载的：在文件夹里运行 `git pull`。
   - 用 ZIP 下载的：下载新的 ZIP，把里面的文件**覆盖到原来的文件夹里**。不要另外加载一个新文件夹，否则会读不到原来的资料。
3. 回到 `chrome://extensions`，点这个扩展卡片上的刷新按钮（↻）。

## 使用流程

按工作台左侧的 1～6 步依次进行。

### 1. 作者资料
填写真实姓名、手机、邮箱和地址。这些是投诉表单里反复要填的内容，填一次就够了。

身份证和合同的扫描件不放进工具。工具只记下它们放在哪个文件夹，上传时由你自己选文件。

### 2. 作品库
**最快的添加方法：粘贴晋江作品链接，点「读取并添加」。** 电脑版链接（`onebook.php?novelid=…`）和手机版链接（`m.jjwxc.net/book2/…`）都可以。工具会自动读取下面这些信息，你核对无误后点「保存作品」：

- 书名、笔名、文案、正版链接
- 首发时间（第 1 章的首发时间）
- 分类、连载状态、字数和标签（写进备注）
- 候选指纹句：从免费的第 1 章里自动挑 3 句叙述句

有两项需要你自己补：
- **旧书名**：晋江页面上不显示。
- **付费章节的指纹句**：再补 2～3 句。盗文站最想偷的就是付费内容，用付费章节的句子来核验最准。

编辑已有作品时，「从晋江补全空着的项」只会填写空着的格子，不会覆盖你改过的内容。

每本书最终需要这几项信息：书名、旧书名、笔名、正版链接、首发时间。

其中最重要的是**指纹句**：从正文里挑 3～5 句有辨识度的原句，最好来自付费章节，每句 15 字以上。工具会用它们来：

- **搜索**：取每句的前 24 个字去搜；
- **核验**：检查盗文页面里有没有出现这些句子。

> 千万不要删文、删号重发。首发时间是你证明自己是作者的关键证据。

### 3. 搜索盗文
1. 勾选要搜的作品和搜索入口（百度、夸克、必应等），点「开始搜索」。
2. 工具会另开一个「搜索窗口」，一条一条地搜。**搜索期间请不要关掉工作台页面。**
3. 如果某个搜索引擎要求验证，工具会暂停，并切换到搜索窗口。你手动完成验证后，回到工作台点「我已完成验证，继续」。
4. 很多盗文站只在手机上显示正文。遇到这种情况，可以在「设置」里打开「用手机身份搜索、核验和截图」。

### 4. 人工审核
每条候选链接都会显示疑似度、是在哪个搜索引擎上发现的、摘要，以及类型（网页、网盘、社交平台）。按下面的步骤审核：

1. **核验**：工具会抓取页面，检查里面有没有书名和指纹句，结果类似「指纹 2/3，含书名」。第一次核验时，Chrome 会问是否允许访问网站，点允许即可。
2. **打开看**：自己点开链接确认。也可以按 `O` 打开当前这一行。
3. **标记**：把链接标成盗文、推文、正版、失效、空壳或无关。
   - 快捷键：`J`、`K` 上下移动；`1` 盗文、`2` 推文、`3` 正版、`4` 失效、`5` 空壳、`6` 无关；`V` 核验。
4. **截图取证**：工具会打开页面并截图，在图片底部印上网址、页面标题和取证时间，存到你的下载文件夹。

**怎么判断：**

| 情况 | 标成 |
|---|---|
| 页面里有正文 | 盗文 |
| 网盘里是文包 | 盗文 |
| 只是推荐，不放正文也不放资源 | 推文（不要投诉） |
| 晋江或合作渠道 | 正版（千万不要投诉） |
| 有书名，但页面上只有广告 | 空壳 |
| 打不开、404 | 失效 |

### 5. 投诉材料
确认过的盗文会自动按「四档」分好组：

| 档位 | 分组方式 | 怎么投诉 |
|---|---|---|
| 第一档：盗文网页 | 按发现它的搜索引擎分组 | 向对应的搜索平台提交版权投诉，删掉搜索结果；也可以走晋江的快速通道 |
| 第二档：网盘 | 按网盘服务商分组 | 分别向各家网盘投诉 |
| 社交平台 | 按平台分组 | 逐条投诉（投诉前再确认一遍不是推文） |
| 第三档：域名 | 列出所有盗文站的域名，附 ICANN 查询链接 | 查出注册商和托管服务商，再向服务商投诉 |

每一组都可以复制链接，也可以复制或下载权利通知书。通知书按《信息网络传播权保护条例》要求的要素生成：权利人身份、联系方式、作品名称、侵权网址和承诺声明。投诉成功后点「记录为已投诉」，下次打开就能看到哪些链接已经投诉过了。

**投诉页的地址需要你自己填。** 各平台的版权投诉入口经常变，所以工具里没有预先写好。请从作者区的打盗教程里找到地址，核对无误后填进「设置 → 投诉入口」。

### 一键填好必应表单
在「投诉材料 → 第一档 → 在必应上发现」这一组里，点「一键填好必应表单」。工具会打开必应的版权投诉表单，自动填好：

- 姓名、版权人、国家、邮箱
- 作品类型、书名、正版链接
- 英文说明
- 所有还没向必应投诉过的盗文链接（超过 10 条时，会自动生成 txt 文件批量上传）
- 附件：中英文的权利通知书

页面顶部会出现一条提示。表单里画了红框的三项声明、电子签名和 Submit 按钮，需要你核对后**自己**勾选、签名、提交。提交成功后，点提示条上的「我已提交成功，记录投诉」。

使用前，请先在「作者资料」里填好拼音姓名和邮箱。必应会把投诉信息转给对方，或者公开出来，所以建议用一个打盗专用的邮箱。

### 一键填好夸克表单
在「投诉材料」里，夸克网盘那一组（第二档）和「在夸克上发现」的网页那一组（第一档）都有「一键填好夸克表单」按钮。

第一次用之前，请先登录夸克侵权投诉平台（ipp.quark.cn），在「实名认证」里添加好权利人。

点按钮后，工具会打开投诉平台，自动完成这些：
- 依次选好「权利人 → 知识产权 → 著作权 → 夸克网盘（或夸克搜索）→ 小说」，并选上权利人；
- 逐行填入侵权链接、作品名称和访问码（一次最多 50 条）。访问码从链接里的 `pwd=`，或者备注里的「提取码：xxxx」读取；
- 写好投诉描述。

剩下的由你自己完成：在红框处上传证明文件（签了字的通知书、首发证明或合同；「可打印的通知书」按钮可以生成一份）和侵权截图，核对后点「提交」。提交成功后，点页面底部提示条上的「我已提交成功，记录投诉」。

### 6. 投诉跟踪
所有记录为「已投诉」的链接都列在这里，能看到每条投诉过哪些平台、是哪天投诉的。

- **复查链接**：重新打开每条链接，看它还在不在。结果分四种：
  - **已失效**：打开是 404，或者网盘提示「分享不存在 / 已失效」；
  - **仍可访问**：页面里还能找到书名或指纹句；
  - **待确认**：页面还在，但看不出是不是你的文，需要你打开看一下；
  - **未复查**：还没复查过。
- **重新搜索**：用当初找到这些链接的搜索词再搜一遍。「搜索结果」一栏会显示投诉之后它还能不能被搜到。重新搜索也会计入每天的搜索次数。
- 仍可访问的链接可以点「再投诉」，回到投诉材料再投一次。
- 点「导出表格」可以把整张跟踪表存成 CSV 文件。

平台处理投诉一般需要几天，建议投诉一周后再复查。

### 填写助手（在投诉页面上用）
1. 打开某个平台的投诉页面。
2. 点工具栏里的「打盗工作台」图标，选「在当前页面打开填写助手」。
3. 先点表单里要填的输入框，再点助手里的条目（姓名、作品名、侵权链接、通知书全文等），内容就会填进去。
4. 要逐条填多个链接时，可以选「追加到末尾」。

助手只负责填写。勾选协议、上传证件、输入验证码、提交，都要你自己完成。提交成功后，可以在助手底部记录这次投诉。

如果投诉表单嵌在 iframe 里，助手可能填不进去。这时可以点每个条目旁边的「复制」，再手动粘贴。

## 权限说明

| 权限 | 用途 |
|---|---|
| 存储 | 把资料保存在本机 |
| 标签页、脚本注入 | 打开搜索窗口、读取搜索结果、在投诉页面打开填写助手 |
| 访问搜索引擎网站 | 读取百度、夸克、必应、搜狗、360、头条、微博的搜索结果页 |
| 访问晋江、夸克投诉平台 | 读取晋江的作品信息；在夸克侵权投诉平台上填表 |
| 访问所有网站（可选，第一次核验或截图时才会询问） | 核验盗文页面内容、截图取证。可以随时在扩展详情页关闭 |
| 修改请求头 | 只在开启「手机身份」时使用，让搜索窗口和核验请求看起来像手机浏览器 |

工具不会把你的资料发送给任何第三方服务器。

## 注意事项

- **举报的责任在举报人。** 有的平台收到投诉会直接屏蔽链接。如果误报了正常的推文或正版渠道，对方可以申请恢复，甚至追究举报人的责任。每条链接都请亲自打开确认。
- **控制搜索频率。** 默认每两次搜索间隔 20～45 秒，单轮最多 30 次，每天最多 120 次。调得太快会被搜索引擎软封禁，之后连续几天都可能搜不出结果。
- **不要把这个工具改成「全自动提交」再分享给别人。** 坛友提醒过，这样做有法律风险。
- **导出的备份文件里有你的真实信息**，不要发给别人，也不要传到 GitHub 上。
- 如果想推荐给其他作者，请直接分享这个仓库的链接，不要转发改过的版本，并建议对方自己看一遍代码。所有代码都在仓库里，没有打包或压缩，可以直接阅读。

## 已知局限

- 目前只用模拟的搜索结果页测试过，还没在真实的百度、必应页面上跑过。搜索引擎的页面结构会变，如果某个入口突然一条结果都读不出来，多半是页面改版了。夸克、头条/悟空、微博用的是通用解析，准确度不如百度、必应、搜狗、360。
- 有些盗文站用 JavaScript 加载正文，或者对正文做了混淆。核验这类页面时，可能会显示「无书名」或「页面几乎无文字」，需要你打开页面自己判断，再截图取证。
- 少数结果是搜索引擎的跳转链接，工具解析不出真实网址，会标上「跳转链接」。点「核验」或者手动打开，就能看到真实网址。
- 工具只负责发现、整理和填写。投诉能不能成功，取决于各平台的审核。
